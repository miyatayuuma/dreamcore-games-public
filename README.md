# DreamCore Games — 公開コード版

このリポジトリは、ブラウザゲームの一般公開可能なソースコードを、過去の非公開Git履歴を引き継がずに保存・開発するためのものです。

## 現在収録しているゲーム

- **CORE BREAK** — 数を使ったゲーム
- **FACTOR RAID** — 素因数のゲーム

現時点では、個人向け画像を含むゲーム、素材権利の確認が必要なゲーム、短編作品、および第三者制作BGMの音声ファイルは移行していません。公開できるコードと素材の確認が済み次第、段階的に移行します。

共有BGMの機能は、この公開版では無効です。既存のFirebase Hosting本番環境はこのリポジトリからデプロイしません。

## 検証

```sh
node scripts/verify-number-games.mjs
node --test tests/core-break/*.test.mjs
```

公開CIは上記のみを実行し、管理者認証情報や本番デプロイを扱いません。現時点では第三者への利用・再配布ライセンスを付与していません。
