# DreamCore Games — 公開コード版

このリポジトリは、ブラウザゲームの一般公開可能なソースコードを、過去の非公開Git履歴を引き継がずに保存・開発するためのものです。

## 現在収録しているゲーム

- **モンスターラッシュ** — 架空の代替モンスター画像を用いた移植版
- **チャージ＆クラッシュ** — 架空の代替敵画像を用いた移植版（Three.js 0.160.0の外部CDNを利用）
- **CORE BREAK** — 数を使ったゲーム
- **FACTOR RAID** — 素因数のゲーム

未移行：あおちゃんクイズ、迷子のヤモリ、七夕の夜、短編作品。元の写真・イラストや第三者制作BGMの音声ファイルは移行していません。今回の2ゲームでは元画像を公開せず、架空のSVG代替素材に差し替えています。元の見た目と完全に一致するわけではありません。公開できるコードと素材の確認が済み次第、段階的に移行します。

共有BGMの機能は、この公開版では無効です。既存のFirebase Hosting本番環境はこのリポジトリからデプロイしません。

## 検証

```sh
node scripts/verify-number-games.mjs
node --test tests/core-break/*.test.mjs
```

公開CIは上記のみを実行し、管理者認証情報や本番デプロイを扱いません。現時点では第三者への利用・再配布ライセンスを付与していません。
